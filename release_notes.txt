# Smart Window Tool v1.4.3

修复 v1.4.2 保活预热导致屏幕左上角每 45 秒闪现二级菜单的问题。

## 修复内容

- 根因：45 秒保活的预热把「自定义窗口尺寸 / 移动到显示器」两个悬停弹窗直接 IsOpen 打开做渲染预热——弹窗是独立置顶窗口，宿主菜单在屏幕外时 WPF 把弹窗放到了可见屏幕左上角 (0,0)，每次保活闪现约 170ms。
- 预热改为只对弹窗内容做测量/布局（模板、列表项、JIT），不再创建弹窗窗口，任何情况下都不会产生可见界面；预热收益（首次呼出/悬停不卡）保留。
- 实测验证（10ms 粒度窗口探针 + perf-trace）：修复前每 45 秒两个 192px 弹窗在 (0,0) 可见约 170ms；修复后 105 秒覆盖两轮保活 tick，弹窗窗口全程零出现，保活 tick 正常执行（约 40ms）。

# Smart Window Tool v1.4.2

呼出速度与可靠性优化：开机后、长时间未使用后首次呼出由数百毫秒到数秒级降至约 60ms；修复长时间闲置后热键可能彻底失效的问题。

## 优化内容

- 启动 2 秒后在屏幕外完成预热（布局/渲染/JIT/定位计算），开机自启后第一次呼出不卡。
- 呼出路径的黑名单查询（跨进程 MainModule）与显示器枚举（Screen.AllScreens）改为 30 秒缓存；悬停「移动到显示器」时才强制刷新显示器列表。
- 进程优先级提升到正常：计划任务默认以「低于正常」优先级（7）启动进程，CPU 紧张时菜单抢不到时间片；自启动任务同时调整为优先级 5 并允许电池模式下启动。
- 每 45 秒保活一次（菜单隐藏时屏幕外重渲染），防止长时间闲置后工作集被系统换出导致首次呼出变慢。
- 修复长时间闲置后菜单可能彻底呼不出的问题：钩子回调改为异步派发——原先同步等待 UI 线程，内存紧张时回调变慢会被系统按 LowLevelHooksTimeout 静默移除全局钩子，热键永久失效；同时每 45 秒重装钩子自愈。
- 新增性能诊断：呼出超过 80ms 自动把分段耗时写入 %APPDATA%\SmartWindowTool\perf.log；创建 perf-trace.flag 可开启全程跟踪 perf-trace.log（平时零开销）。
- 实测（真实鼠标注入对照）：首次呼出 526ms → 162ms；稳定呼出约 60ms；内存回收加闲置后首次 >8 秒甚至失效 → 57ms。

# Smart Window Tool v1.4.1

呼出菜单的悬停子菜单（自定义窗口尺寸 / 移动到显示器）加入安全三角，斜向划动不再轻易收起。

## 修复内容

- 斜向划向子菜单时，弹窗不再因为「划过按钮与弹窗之间的缝隙」而消失：离开按钮/弹窗后以退出点对弹窗近边建立安全三角，三角内保持展开。
- 安全三角底边向两端外扩 2 倍按钮高度，覆盖「按钮下方绕行再斜向弹窗」的路径；显示器列表这类矮弹窗同样有效。
- 划过「移动到显示器」按钮不再瞬间顶掉已展开的尺寸弹窗：切换子菜单增加 250ms 悬停意图延迟，停住才切换。
- 离开安全区后保留 200ms 收起宽限，快速划过、或划出弹窗边缘又折返都不会误关；真正移开仍会及时收起。
- 弹窗开合改用屏幕坐标矩形判定，替换原先依赖 IsMouseOver 的 50ms 定时判断，行为更稳定。
- 新增安全三角几何单元测试（全部 50 项通过），并用真实鼠标注入对新旧构建做过界面对照验证（旧版斜扫弹窗消失、新版保持展开）。

# Smart Window Tool v1.4.0

新增可独立启停和切换模式的进程黑名单，并加入简洁版应用图标。

## 新增内容

- 每条黑名单可单独选择“完全黑名单”或“仅功能黑名单”。
- 每条黑名单带独立“启用”开关，停用后不会删除配置。
- 完全黑名单：不呼出 SmartWindowTool 菜单，快捷键和滚轮功能也不生效。
- 仅功能黑名单：仍可呼出菜单，但菜单操作、快捷键和滚轮调节均停用。
- 旧版字符串黑名单配置继续兼容，默认按“完全黑名单”处理。
- 使用简洁窗口图标作为应用图标和托盘图标。
- 托盘图标改为内嵌到单文件中的自定义图标，不再依赖发布目录旁的额外 ICO 文件。
- 修复黑名单条目中盾牌图标与进程路径重叠的问题，长路径会显示省略号并可悬停查看完整路径。

# Smart Window Tool v1.3.3

修复进程黑名单失效问题。

## 修复内容

- 黑名单匹配同时支持完整路径与进程名，不再把「裸进程名」与整条路径做全等比较（原先按路径添加的黑名单永远不生效）。
- 键盘快捷键（Alt+数字、Ctrl+数字、Ctrl+Alt+方向键）与滚轮调节（透明度/宽度/高度）现在同样受黑名单约束，之前只有鼠标菜单受约束。
- 黑名单条目自动去除首尾空白与引号，重复添加不再区分大小写。
- 新增黑名单匹配与应用内真实进程的集成测试。

# Smart Window Tool v1.3.2

本版本调整开机自启动路径行为：从哪个 EXE 开启自启动，下次登录就直接运行哪个 EXE。

## 修复内容

- 计划任务直接记录当前正在运行的 `SmartWindowTool.exe` 完整路径。
- 不再把程序复制到固定的 `%ProgramFiles%\SmartWindowTool` 目录。
- 不再把自启动路径重定向到托管副本。
- 更新 README，明确移动或删除已绑定的 EXE 会导致自启动失效。
- 增加任务创建参数回归测试，确保始终保留当前 EXE 路径。
- 全部 24 项测试通过。

## 使用说明

- 切换自启动程序位置前，请先完全退出正在运行的旧实例。
- 从目标 EXE 启动程序，然后关闭并重新开启“开机自启动”。
- 单实例机制生效时，再次双击其他位置的 EXE 只会激活已有实例。

## 下载与运行

- 下载 `SmartWindowTool-v1.3.2.exe` 后直接运行。
- 需要 Windows 10 或 Windows 11。
- 需要安装 .NET 8 Windows Desktop Runtime。
